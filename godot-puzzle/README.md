# Construction Kingdom - Puzzle demo (Godot 4)

Ce dépôt contient une démo de jeu de puzzle (sliding-tile) réalisée pour Godot 4.

Comment ouvrir et jouer :

1. Installez Godot Engine 4.x (https://godotengine.org).
2. Ouvrez le projet Godot : ouvrez le dossier `godot-puzzle` dans Godot.
3. Ouvrez la scène `res://scenes/Main.tscn` et lancez-la.

Contrôles :
- Cliquez sur une tuile adjacente à la case vide pour la déplacer.
- Utilisez le bouton "Restart" en haut à droite pour mélanger les tuiles.

Structure :
- scenes/Main.tscn - scène principale
- scripts/Game.gd - logique du jeu (GDScript)
- project.godot - fichier de projet Godot 4
